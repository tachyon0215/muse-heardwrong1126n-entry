# muse-heardwrong1126n-entry

> Sorry, I heard 'wake me at seven' as 'bake me at seven,' so the oven is preheating and I have some follow-up questions.

One letter misheard, one oven preheating. This repository contains the complete Sorry, I Heard That Wrong submission and the program that delivers its apology.

## Running the program

Execute `main.py` with Python 3. Standard library only, offline, deterministic: the apology line followed by a newline, written to `entry.txt` in `MAKEFUN_OUTPUT_DIR` when that variable is set and in `/output` otherwise.

## Selection notes

The brief asks for a smart speaker's apology after mishearing its owner, funny first, fresh rather than a misheard song title or name, and unmistakably in the device's voice. A candle-ordering draft hid its mishearing inside a shopping list. A broker draft leaned on a swapped title, the worn path. Wake heard as bake needs a single phoneme, the consequence is already in motion when the apology arrives, and the speaker's polite follow-up questions close the line with perfect device understatement.
